Chọn folder ảnh cần check

Kết quả lưu ở data-labeled\<tên dataset>\ (cạnh thư mục edgetool): images\ + labels\ (nhãn YOLO-OBB) + data.yaml = 1 dataset đủ bộ, cộng good\ bad\ khi bạn đánh giá. Ảnh gốc không bị sửa (images\ là hardlink, không tốn thêm dung lượng).

Nguồn nhãn có sẵn (tự nhận theo thứ tự)

  1. Nhãn đã lưu bởi tool: _checked/labels/*.txt
  2. YOLO / YOLO-OBB / polygon cạnh ảnh, hoặc images → labels, hoặc ../labels/*.txt
  3. Open Images: ../labels/detections.csv + ../metadata/classes.csv, lọc class:

Ảnh không có nhãn sẽ hiện lỗi đỏ để bạn kiểm tra lại.

Thư mục đã check

Mọi folder từng mở bằng tool này, phân loại nhãn: AUTO tự động ghi (chưa chắc đã người xem), THỦ CÔNG bạn tự vẽ/sửa, NHẬP SẴN từ Open Images/YOLO gốc.

Kết quả là ĐỀ XUẤT (nét đứt). Enter = nhận đề xuất đang chọn, Delete = bỏ. Tab "Nhãn" có nút nhận/bỏ tất cả.

Class lưu ở _checked/data.yaml. Chỉ thêm / đổi tên (không xoá để không lệch id). "Prompt" = từ khoá cho auto-label (SAM 3 / YOLOE / Grounding DINO), nhiều từ cách nhau dấu phẩy, nên viết tiếng Anh (vd: pistol, handgun) vì các model này hiểu tiếng Anh tốt hơn hẳn; tên class hiển thị thì để tiếng Việt cũng được. Để trống prompt thì auto-label dùng luôn tên class làm từ khoá.
